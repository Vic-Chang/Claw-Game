# 飛絡力標準台 三爪娃娃機（真實物理網頁遊戲）

在瀏覽器裡玩一台「飛絡力標準台」三爪娃娃機：爪力、摩擦力、鋼索甩動、碰撞都由物理引擎即時計算，台主中控面板（選單 A～G）的每個設定都會真的改變機台行為。

## 操作

| 動作 | 鍵盤 | 觸控 / 滑鼠 |
|---|---|---|
| 投幣 | `C` | 「投幣」鈕 |
| 移動天車 | 方向鍵 / `WASD` | 左下搖桿 |
| 取物（下爪）；下爪途中再按＝空中取物（二收） | 空白鍵 / Enter | 「取物」鈕 |
| 切換視角（正面 / 側面 / 俯視 / 跟隨爪子） | `V` | 「視角」鈕，可拖曳旋轉 |

右上角「🔑 台主模式」打開機台內部：

- **中控面板**：仿飛絡力黃綠 LCD，按「設定」進入功能選單，▲▼ 選擇／加減，◎（取物鍵）確認・儲存・離開；「試玩」鍵免費試玩（不入帳）。
- **參數表**：所有設定的中文說明與數值，和中控面板雙向同步，自動保存在瀏覽器。
- **爪子調整**：爪子大小、爪距（開度）、爪套材質／摩擦係數、防甩片凹度與方向（可三爪連動或個別調）。
- **機台佈置**：各種獎品的數量與擺法（補貨）。
- **物理監看**：即時電壓、爪子閉合度、爪頭高度、鋼索鬆弛曲線與數值。

## 為什麼用 MuJoCo（WASM）

真實感的關鍵在「夾取」，所以物理引擎選擇以夾爪模擬見長的 **MuJoCo**（Google DeepMind 官方 `@mujoco/mujoco` WebAssembly 版），而不是一般遊戲引擎：

| | Rapier / cannon-es | Jolt | **MuJoCo** |
|---|---|---|---|
| 爪力 | 關節馬達 | 鉸鏈馬達 | 真實致動器（力矩上限、彈簧、阻尼） |
| 摩擦 | 線性庫倫摩擦 | 庫倫摩擦 | 橢圓摩擦錐＋扭轉＋滾動摩擦 |
| 鋼索 | 繩關節 | 約束鏈 | 只能拉不能推、會鬆弛的 tendon |
| 夾持穩定度 | 易抖動、滑脫、穿透 | 中等 | 機器人夾爪模擬標準 |

- WASM 是必要條件：純 JavaScript 物理撐不住 2 ms 時間步與高迭代數的接觸求解。
- 物理和中控板在 **Web Worker** 以 500 Hz 運算，主執行緒只負責 Three.js 繪圖與介面；畫面處理不及時 Worker 會自動降頻送畫面（不會塞車）。
- 預設單執行緒 WASM，任何現代瀏覽器、GitHub Pages 都能直接跑。

## 物理模型

- **天車**：X/Y 滑軌＋速度型馬達（有限推力、質量 2.2 kg），急停時爪子會因慣性擺動；E8 加快轉速時會「打滑」。
- **鋼索**：MuJoCo spatial tendon，長度上限＝絞盤放出的線長。只能拉不能推；爪子著地時鋼索鬆弛（機台以此判斷「到底」）。擺動週期符合 T ≈ 2π√(L/g)。
- **頂部管子**：A12 上停上拉會把爪頭拉進管子，產生真實的頓挫甩動。
- **電磁閥**：電流 I = V/R（16 Ω），鐵芯飽和，拉力 ∝ I²，爪子越閉合拉力越大；線圈電感使電壓切換有約 30 ms 的漸變。電壓太低時拉力小於回位彈簧，爪子合不起來。
- **三爪**：每支爪是有質量的鉸鏈剛體，彈簧讓爪子斷電自然張開；爪尖爪套與防甩片都是實際的碰撞形狀。
- **獎品**：餅乾盒、面紙盒（硬紙盒）、飲料瓶，以及由頭／身體／四肢＋彈簧球關節組成、接觸較軟的絨毛娃娃。
- **出獎口**：壓克力擋板是真的牆；洞內「落物電眼」偵測到獎品才算中獎。
- **摩擦優先權**：爪子零件的接觸參數優先（MuJoCo geom priority），所以換爪套會真正改變爪子和獎品間的摩擦。

## 飛絡力中控設定（依影片）

設定項目、代碼與 LCD 文字依照 **小雞女蛋蛋〈我買了一台娃娃機！娃娃機設定大公開！〉**（2023 年製飛絡力標準台、JS 爪）逐段整理。

| 選單 | 內容 |
|---|---|
| A 基本設定 | A1 投幣器（一投／每局）、A2 遊戲時間、A3 禮品售價（保夾金額，最高 1990 元）、A4 選物累加（顯示、保留時間）、A5 展示音樂、A6 空中取物（二收、延遲收爪）、A7 投幣儲存、A8 下爪延遲（段亂數）、A9 上停延遲、A10 下爪 & 夾亂數、A11 下停上拉延遲、A12 上停上拉 / 回停下降、A13 促銷功能、A14 下爪長度時間（線長） |
| B 抓力電壓設定 | B1 強電壓、B2 中電壓、B3 弱電壓（0.0～48.0 V）、B4 中壓距離頂點（1～30）、B5 保夾的強電壓 |
| C 查帳 | C1 中獎率銀行、C2 投幣遊戲次數、C3 禮品出獎次數、C4 累加金額查詢（最近 10 筆）、C5 全部歸零 |
| D 自動模式 | 免費（5 秒後開始、之後每 10 秒一局）、機台耐久測試（每 15 秒自動跑一次） |
| E 馬達速度 | E1～E4 前後左右、E5 往下、E6 往上（影響「丟」的幅度）、E7 全部 100%、E8 前後左右轉速 |
| F 測試 | F1 落物電眼測試（OK / NG）、F2 投幣器測試 |
| G 進階設定 | G1 防電擊警告、G2 回復原廠設定、G3 上停異常理線（開爪 / 閉爪） |

爪子一局的流程（中控板狀態機）：
（A8）下爪（E5、A14、可 A6 二收）→ 強電壓 B1 合爪（保夾局用 B5）→（A11）上升（E6）→ 距頂點 B4 轉中電壓 B2 → 頂到管子再上拉 A12 → A9 上停延遲 → 弱電壓 B3 回原點 → A12 回停下降 → 開爪 → F1 電眼判定出獎。
保夾：累加金額 ≥ A3 時，該局全程使用 B5，出貨後累加歸零。

### 影片未說明、本模擬自行推測的部分

參數表中標示「推測」：

- A5、A6 延遲、A9、A10、A11、A12、A14 的數值上限（影片只示範了部分數值）。
- A13 促銷功能：作者也不清楚，實作為「每 N 局送一局」。
- G1 防電擊警告：只保留開關選項，不影響遊戲。
- C1 中獎率銀行：實作為「自上次出貨後投入的金額」。
- B4 每一格約等於 1.8 cm 線長。
- 實際電壓對應的爪力是依真實量級校準：48 V 時單爪尖約 3 N。

## 開發

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # 中控板邏輯 + 物理驗證 + 整局遊戲測試
npm run build      # 輸出 dist/（靜態網站，可放 GitHub Pages）
```

測試涵蓋：

- **中控板**：A1～A14、B4、保夾、A4 逾時、A7、A13、D 自動模式、E 速度。
- **物理**：摩擦臨界角、電磁閥飽和與 L/R 時間常數、鋼索單擺週期、爪子大小與擺動、鋼索鬆弛、電壓與夾取成功率、爪套摩擦差異、爪距／防甩片幾何、防甩片改變甩出軌跡、重建模型時獎品位置不變、出獎電眼。
- **整局**：保夾局可把獎品送進出獎口；弱電壓 0 V 一定在途中掉落。

## 已知限制

- 絨毛娃娃是多剛體＋軟接觸，不是有限元素的布料／棉花模擬。
- 甩動與防甩片的效果對細節極為敏感（就像真實機台），同樣操作每次結果可能不同。
